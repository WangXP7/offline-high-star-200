## 2. 背景和问题定义

远端当前最后一个公开版本为 `v3.2.0`。本地 v3.3～v3.5 已完成性能、百人房、外观同步、统一首页和局域网稳定性改进，但尚未提交或发布。

v3.5 已共享模式目录、移动速度、半径、分裂门槛、分裂冲量、部分刺球和吐球拾取公式，但单机与联机仍分别维护完整会话循环。确定存在以下规则漂移：

1. 单机 `updateEjected` 包含孢子喂刺和发射刺球，服务端 `updateEjected` 没有该碰撞阶段；
2. 单机部分模式事件、AI 策略和表现仍写在大型页面脚本中，服务端存在独立实现；
3. 单机与联机的键盘导航、暂停/退出层级和大厅入口不同；
4. 主菜单不能直接管理局外养成，玩家需要先进入旧单人大厅；
5. 桌面全屏按钮失败时没有反馈，关于页外链只允许 GitHub 且失败静默；
6. Squirrel.Windows 为无提示安装器，不能满足用户选择安装目录的要求。

v3.6 不把联机继续当作独立玩法实现。唯一允许分离的是“权威状态从哪里产生”和“状态如何传输”；玩法规则、模式配置、外观和结果语义必须只有一个来源。

## 3. 产品目标

### 3.1 必须完成

1. 十种模式全部支持单机和局域网联机：自由、团队、生存、大逃杀、闪电、孢子、霸屏、据点、巨行星、魔王。
2. 十种模式读取同一份模式目录，并调用同一批纯玩法函数；不得为联机复制或缩减规则。
3. 单机为 1 名真人加 AI；联机为 2～8 名真人，AI 自动补至同一模式目标人数。
4. 恢复联机孢子喂刺、推动/发射刺球，并与单机的质量阈值、方向、速度和刺球数量上限一致。
5. 主菜单直接提供外观、成长、商店与锻造入口；当前装备自动用于单机和联机。
6. 设置提供窗口化和无边框全屏，F11、设置项和快捷按钮状态一致并持久化。
7. 关于页提供 GitHub、QQ、CSDN、小黑盒和哔哩哔哩入口，成功与失败均有可见反馈。
8. Escape 在主菜单、子页面、单机大厅、联机大厅、等待房间和对局中具有一致的返回/暂停/退出行为。
9. Windows 提供可选择安装目录的引导式安装程序和可解压到任意目录的便携版。
10. 通过自动化、一致性、双实例、性能、打包和人工双机验收后发布 GitHub `v3.6.0`。

### 3.2 非目标

- 不把每个联机客户端变成独立权威；联机仍由房主内置服务器裁决。
- 不承诺互联网跨公网自动打洞、账号云同步或官方常驻服务器。
- 不修改历史单 HTML 版本。
- 不使用显卡型号作为规则正确性或网络流畅度的判断依据。
- 不在 v3.6 引入影响数值平衡的付费内容。

## 4. 规范架构

```text
统一首页 / 设置 / 个人中心 / 输入映射 / 场景表现
                         |
                  ClientSession API
                 /                 \
      LocalAuthority 60 Hz     NetworkAuthority
        本机执行共享规则        输入 -> 房主服务器
                 \                 /
          Canonical Gameplay Core
   实体公式 / 碰撞 / 分裂 / 吐球 / 刺球 / AI / 模式插件
                         |
                  Canonical Mode Catalog
```

### 4.1 共享玩法内核边界

以下逻辑必须是无 DOM、无 Canvas、无 WebSocket、无 Electron 依赖的纯函数或确定性状态转换：

- 质量与半径、大小与速度、转向和阻尼；
- 出生、复活、无敌、分裂、分身冲量、合体冷却；
- 吐球成本、吐出物速度/寿命/拾取保护；
- 食点拾取、细胞吞噬、队友接球；
- 普通刺/大刺分裂、孢子刺爆散、吐球喂刺和刺球发射；
- 安全区、圈外伤害、生命、淘汰与胜负；
- 据点占领、霸屏覆盖、闪电制霸和魔王角色/技能数值；
- AI 出生质量、目标评分、队伍与模式约束；
- 排名、奖励输入和结果摘要。

页面只负责输入、声音、特效、渲染和 UI；服务器只负责持有权威状态、固定步进、协议校验和快照；两者不得各自发明规则常量。

### 4.2 权威适配器允许的差异

| 项目 | 单机 | 联机 |
| --- | --- | --- |
| 权威位置 | 当前进程 | 房主内置服务器 |
| 物理频率 | 60 Hz | 30 Hz 固定步进 |
| 输入 | 本地输入队列 | 60 Hz 上报并 ACK |
| 显示 | 当前/上一状态插值 | 快照缓冲、本地预测与校正 |
| 暂停 | 可真正暂停 | 只暂停本地菜单，服务器继续 |
| 断线 | 不适用 | AI 接管、限时重连 |
| 房间 | 不适用 | 发现、加入、准备、房主控制 |

这些差异只能影响传输和时间采样，不能改变最终规则语义。所有以秒表示的规则必须乘实际 `dt`，不得依赖固定帧数产生 30/60 Hz 差异。

## 5. 十模式统一契约

| 模式 | 总人数 | 核心验收 |
| --- | ---: | --- |
| 自由 | 100 | 限时复活，按个人质量排名 |
| 团队 | 40 | 10 队 × 4 人，友军不能被敌对规则吞噬，可接队友分身 |
| 生存 | 64 | 3 条生命、击杀奖励、生命耗尽永久淘汰 |
| 大逃杀 | 100 | 无复活、安全区收缩、最后存活者胜利 |
| 闪电 | 88 | 高速成长、随机事件、制霸判定一致 |
| 孢子 | 48 | 孢子刺爆散和质量守恒，吐球可喂刺 |
| 霸屏 | 22 | 方形场地、64 分身、A 快合、D 冲刺种刺、覆盖胜利 |
| 据点 | 28 | 4 队 × 7 人、3 个据点、占领与积分结算一致 |
| 巨行星 | 36 | 巨球出生、固定区域、霸屏占比和保持时间一致 |
| 魔王 | 10 | 勇者/魔王/魔兵角色、技能、胜负和超员约束一致 |

真人优先占用目标名额，AI 数量为 `max(0, targetParticipants - connectedHumans)`。除魔王角色完整性约束外，联机不得通过人数上限、食点缩减、刺球关闭或 AI 简化改变模式。

## 6. 吐球喂刺统一规则

1. 吐出物先按共享运动函数移动和衰减；
2. 在被细胞拾取前检测刺球外缘碰撞；
3. 命中后吐出物立即从权威状态移除；
4. 刺球累积同一共享倍率的质量；
5. 达到类型阈值后，按吐出物到刺球的方向重置原刺质量并生成/发射新刺球；
6. 发射刺球位置和速度必须进入病毒 revision delta，客户端不得等下一次完整基线；
7. 刺球数达到模式上限时仍消耗并重置喂养状态，但不超限生成；
8. 同种子和同输入下，本地权威与服务端权威的生成数量、质量和方向允许的误差不超过浮点容差。

## 7. 统一游戏外壳

### 7.1 首页和个人中心

首页正式入口：单人游戏、局域网联机、个人中心、设置、操作方式、关于、退出游戏。

个人中心复用现有本地存档和目录，提供：

- 外观：皮肤、孢子、光环、拖尾与当前装备预览；
- 成长：等级、属性和资源摘要；
- 商店：购买、兑换码和拥有状态；
- 锻造：现有锻造流程与结果；
- 数据：可安全展示的本地战绩和版本信息。

旧单人大厅仍可访问这些面板，但不再是唯一入口。所有页面只操作同一份持久化状态。

### 7.2 显示设置

- 显示模式：`windowed`、`borderless-fullscreen`；
- 窗口尺寸：1280×720、1440×900、1600×900、1920×1080，以及保持当前；
- 帧率、画质、网络缓冲、性能信息、屏幕震动沿用现有设置；
- 桌面主进程报告真实状态，渲染进程不得乐观假设切换成功；
- F11、菜单和 UI 都调用同一个 IPC，并在状态变化事件后更新文字；
- 浏览器版使用标准 Fullscreen API，拒绝时显示提示。

### 7.3 Escape 状态机

| 当前状态 | Escape 行为 |
| --- | --- |
| 设置/关于/操作/个人中心子页 | 返回首页或上一层 |
| 单人大厅 | 返回标题首页 |
| 单人对局 | 打开可暂停菜单 |
| 联机大厅 | 返回标题首页 |
| 联机等待房间 | 离开房间；房主先确认关闭房间 |
| 联机对局 | 打开不中断服务器的退出菜单 |
| 标题首页 | 打开退出游戏确认；浏览器版不强制关闭标签页 |
