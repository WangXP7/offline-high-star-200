# 星团大作战 v4.0.0

v4.0.0 是单机玩法同源联机的首个正式桌面发行版。它保留单 HTML 版和可自行运行的前后端源码版，同时提供普通 Windows 安装程序与便携版。

## 核心变化

- 联机服务器直接加载并执行单机 `frontend/js/game.js`，不再使用旧的独立联机玩法模拟器。
- 十种模式完整开放；真人替换单机参与者槽位，其余人数由同一套 AI 补足。
- 物理固定 60Hz，网络快照 20Hz，客户端画面按显示设置最高支持 240 FPS。
- 完整保留 23 个随机事件、多阶段安全区、魔王/魔兵、普通刺/孢子刺、据点、霸屏技能和模式结算。
- 单机和联机共同调用 `cosmetic-renderer.js` 绘制特殊皮肤、光环和拖尾，修复材质形状偏差。
- 孢子/吐球命中刺球使用空间网格候选查询，避免长局实体增长造成服务器步进恶化。
- 主页、设置和联机大厅使用深色首屏与导航遮罩，避免整页切换时短暂露出 WebView 默认白底。
- 小地图、食点颜色、模式目标、皮肤配置和局外养成均可带入联机。

## Windows 成品

- 安装程序：支持选择安装目录、桌面快捷方式和开始菜单入口。
- 便携版：完整解压 ZIP 后双击 `StarClusterArena.exe`，无需安装 Node.js。
- 两种成品都包含网页前端、Node.js 权威服务和局域网发现模块；创建房间的电脑自动成为房主服务器。

## 验证

- 全量单元与集成测试通过。
- 十模式各 1200 个权威帧压力测试通过，目标人数、快照带宽和 60Hz 步进预算均满足门禁。
- 双实例互相开房、主动退出、自动发现、真实 WebSocket 两人流程与十模式 API 通过。
- 主页与联机大厅连续往返 4 次、设置开关 8 次的逐帧检测中，近白画面比例最大值为 0。
- 窗口化与无边框全屏各完成 5 分钟白屏监测，可疑白帧、WebGL 上下文丢失和 Canvas 异常重建均为 0。
- RTX 5070 Ti / 160Hz 环境下，88 人闪电联机测试约 134～135 FPS，权威快照稳定约 20Hz。

## 网络说明

- 当前正式支持局域网联机，不包含公网中继或云服务器。
- TCP 默认使用 `25555`，占用时尝试 `25557` 或动态端口；UDP 房间发现默认使用 `25556`。
- 首次运行时 Windows 可能询问防火墙权限，请只允许可信的专用网络。
- 路由器 AP 隔离、双方不在同一子网或公用网络防火墙策略仍可能阻止自动发现。
