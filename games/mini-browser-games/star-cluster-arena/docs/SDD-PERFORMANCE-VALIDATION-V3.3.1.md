# 星团大作战：桌面对局性能验证与自适应渲染 SDD v3.3.1

状态：发布候选实施记录
日期：2026-08-25
适用范围：源码版与 Windows 桌面封装版；不修改仓库根目录单 HTML 版本

## 1. 问题与测量原则

v3.3 已取消 WebGL 到 Canvas 2D 的逐帧背景复制，但此前桌面冒烟只验证页面能加载和 GPU 型号，没有进入实际对局持续采样。v3.3.1 必须先建立可重复测量，再决定是否优化 AI、主线程或 GPU。

隐藏 Electron 窗口会被 Chromium 降到约 1 Hz；透明窗口也可能不产生绘制。因此性能采样窗口必须处于可绘制状态，同时放在屏幕外、不显示任务栏，并且仅在测试环境关闭后台与遮挡节流。普通玩家最小化窗口时仍保持默认节能行为。

## 2. 实测根因

- RTX 5070 Ti、160 Hz、1440×900、自由模式 100 星团：修改前实际渲染 133～135 FPS，主线程平均工作低于 1 ms，无长帧。说明高配机已正确调用独显，AI/JavaScript 不是当前瓶颈。
- AMD Radeon 集成显卡使用 0.9x WebGL 背景时帧率波动明显，但主线程仍仅约 0.5～1.5 ms；瓶颈位于 GPU 填充、合成或呈现。
- 原自适应只降低透明 2D 前景倍率；WebGL 背景在前景从 1.25x 降到 1.15x 时仍维持 0.9x，未命中实际瓶颈。

## 3. 设计决策

1. 物理继续固定 60 Hz，不随显示刷新率变化。
2. 显示刷新率不高于 120 Hz 时按实际刷新率渲染；更高刷新率统一限制到 120 FPS。
3. 渲染循环仍在每个 `requestAnimationFrame` 推进固定步进和插值，只跳过超出预算的绘制提交，不跳过输入或物理。
4. RTX/GTX/Quadro、Radeon RX、Intel Arc 等独显的 WebGL 背景倍率上限为 0.9；集成或未知适配器为 0.75。Canvas 2D 前景仍按独立像素预算，当前测试为 1.25。
5. 持续压力时，WebGL 背景可进一步降到 0.6，背景更新频率从 80 降到 60 Hz；细胞、文字和 HUD 不随背景降档消失。
6. 画质压力使用迟滞；严重压力允许一次检查后降档，恢复必须经过更长稳定窗口。
7. 不根据 GPU 型号擅自把整体帧率固定为 90。实测 160 Hz 合成链在 90 FPS 非整除节拍下可能退化到约 30 FPS，因此整体预算保持 120，由分辨率处理 GPU 压力。

## 4. 自动性能采样

命令：

```powershell
npm.cmd run test:desktop-perf
```

可选环境变量：

- `SCA_PERF_MODE`：采样模式，默认 `solo`。
- `SCA_PERF_DURATION`：8～60 秒，默认 16。
- `SCA_PERF_MIN_FPS`：稳态平均 FPS 门槛，默认 55。
- `SCA_PERF_LOW_POWER_GPU=1`：测试时请求低功耗 GPU，用于集成显卡对照；不影响正式启动。

采样必须记录活动对局样本数、平均/最低 FPS、主线程工作时间、长帧、前景倍率、WebGL 倍率、实际适配器、已绘制帧和跳过帧。活动样本不足或低于门槛时进程必须返回非零状态。

## 5. 验收结果

- 全量单元/集成测试新增渲染节拍和适配器背景倍率契约。
- RTX 5070 Ti：稳态平均 119 FPS、最低 118 FPS、最大主线程工作 0.8 ms、长帧 0、WebGL 0.9x。
- AMD Radeon 集成显卡：稳态平均 120 FPS、最低 118 FPS、最大主线程工作 0.7 ms、长帧 0、WebGL 0.75x。
- 新打包便携版的冷启动首个 4 秒样本为 74 FPS，随后依次恢复到 105、118、119 FPS；首段主线程工作仍仅 0.7 ms。验收因此以第 8 秒起的稳态平均值为门槛，同时保留冷启动样本用于发现着色器、缓存或进程启动抖动，不能用冷启动低值替代整局结论。
- 160 Hz 下 16 秒约跳过 220～615 次超预算绘制，物理仍保持 60 Hz。
- 故意设置 240 FPS 门槛时测试返回非零状态，验证失败不会被包装为通过。

上述数值来自当前 1440×900、160 Hz 测试机；其他机器应运行相同命令建立自身基线，不能把具体 GPU 数字当作所有设备保证。

## 6. 发布与回滚

- 协议仍为 `sca-lan-v3`，v3.3.1 与 v3.3 网络兼容；但联机测试时建议所有玩家使用同一构建。
- 若特定集显反馈背景过软，只回调集显背景倍率，不回退双画布或共享移动内核。
- 若帧率上限导致特定高刷屏节拍异常，保留固定 60 Hz 物理并单独回滚渲染节拍函数。
- 十模式动态规则等价迁移仍按 v3.3 SDD 推进，不与本次性能修复混淆。
