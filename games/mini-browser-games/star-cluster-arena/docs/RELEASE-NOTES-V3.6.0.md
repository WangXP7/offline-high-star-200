# 星团大作战 v3.6.0

v3.6.0 是一次面向“共享玩法规则 + 正式 Windows 发行”的更新。仓库中的历史单 HTML 版保持不变；本次更新针对前后端版及由它封装出的桌面版。

## 主要更新

- 十种模式全部可用于局域网联机：自由、团队、生存、大逃杀、闪电、孢子、霸屏、据点、巨行星和魔王。
- 模式人数恢复到原设计目标。房间支持 2～8 名真人，AI 自动补满；例如大逃杀会按当前真人数量补至 100 名参与者。
- 单机和联机共同读取一个模式目录，并共同调用移动、半径、分裂、合球、普通刺、孢子刺、吐球拾取、吐球喂刺和推刺等纯规则函数。
- 修复联机吐球无法推动刺球、普通刺错误产生孢子、吐球拾取反馈滞后和病毒增量不同步等问题。
- 联机继续采用房主权威模拟和客户端预测/插值：画面按显示器目标帧率渲染，权威逻辑固定 30 Hz，不再把联机画面锁在 60 FPS。
- 局外皮肤和装备会带入单机及联机；主菜单可直接进入个人中心，无需先打开单人大厅。

## 桌面体验

- 新增统一开始界面、操作说明、设置、关于、个人中心和联机入口。
- 设置支持窗口化、无边框全屏、窗口尺寸、帧率、画质和网络缓冲；F11、全屏按钮和设置状态保持一致。
- 联机大厅和房间支持 Escape 返回/退出菜单，房主关闭房间前会看到影响提示。
- 关于页加入 GitHub、QQ、CSDN、小黑盒和哔哩哔哩，并对打开或复制结果给出反馈。
- 安装程序改为 NSIS 引导式安装，可选择安装位置；同时提供完整便携 ZIP。

## 下载与运行

- 安装版：运行 `星团大作战-安装程序-3.6.0-win-x64.exe`，按向导选择安装位置。
- 便携版：完整解压 `星团大作战-便携版-3.6.0-win-x64.zip`，再运行目录内的 `StarClusterArena.exe`。不要只复制一个 EXE。
- 局域网联机不需要另租服务器：房主启动内置权威服务，其他玩家在游戏内发现房间或输入房间码加入。
- 第一次联机时，如 Windows 防火墙询问权限，请只允许可信的专用网络。
- 当前发行未购买代码签名证书，Windows SmartScreen 可能显示未知发布者提示。

## 验证结果

- 124 项自动化测试全部通过。
- 十种模式各完成 1200 tick 压力测试，包含 100 人目标房间。
- RTX 5070 Ti / 160 Hz 环境中，打包版单机采样稳定 133 FPS，联机大逃杀采样稳定 135 FPS、权威快照约 30.2 Hz。
- 安装程序已验证安装到非 C 盘、启动和卸载；安装版及便携版均生成 SHA-256 校验值。
- 生产依赖安全审计为 0 项漏洞。

## 联机范围

本版本提供局域网联机，不包含公网自动打洞、官方常驻服务器或账号云同步。实际发布后仍建议两台 Windows 电脑互换房主，重点复测防火墙首次授权、网络发现和十模式手感。
