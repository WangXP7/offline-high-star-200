# 星团大作战 v3.7.0-beta.2

这是一个独立的联机可玩性测试版，不覆盖 `v3.6.0` 稳定成品。

## 修复

- 修复 Electron 沙箱无法执行 ESM 预加载脚本的问题；桌面桥接改用 `preload.cjs`，首页全屏、设置全屏、退出、复制与外部链接恢复可用；
- 显示请求串行执行，避免启动恢复、设置保存和连续点击互相覆盖；
- 全屏测试改为真实点击首页按钮和设置表单，并同时核对 Windows 原生状态、按钮状态、保存值与设置选中项；
- 设置明确区分窗口大小与渲染清晰度，并显示当前内部渲染尺寸和倍率；
- 移除对局内周期性 Canvas 后备缓冲重建，降低整屏白闪风险；
- 服务端食点不再随吞食速度瞬间补满，改为复用单机的时间曲线和有界生成预算；
- 服务端食点质量、高价值食点概率、模式倍率和安全区内分布向单机规则对齐；
- 联机世界恢复为单机的 7600 × 7600；服务端 AI 补入威胁逃跑、食点优先和条件分裂；
- 复活延迟与护盾向单机规则对齐，阻止出生点刷质量；
- 首页、联机大厅和局内增加“联机测试版”标识。

## 当前限制

- 服务端 AI、完整随机事件和多阶段安全区尚未与单机共用同一执行规则；
- 十种联机模式均可测试，但不能称为与单机完全一致；
- 转正式版前仍需要两台电脑互换房主并完成自由、霸屏、大逃杀、团队、孢子和魔王模式人工验收。

## 自动化结果

- Node 测试：147/147 通过；
- Electron 首页按钮进入/退出全屏：通过；
- Electron 设置保存进入/退出全屏：通过；
- 单机与联机霸屏模式各运行 60 秒，稳定约 133 FPS，联机权威快照约 30 Hz；
- 十模式 60 秒人数、食点、击杀、头名质量与总质量门禁：通过；
- 十模式权威模拟与网络体积 soak：通过。
